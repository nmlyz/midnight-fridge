midnight-fridge writes one line to a text file: a smart fridge's reply when asked why it locks after midnight. The line was picked from 36 candidates by pairwise judging against the brief — a three-beat escalation that ends on the fridge's own petty rule. The fridge does not explain itself twice.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 120 characters, a single line, and ends on its strongest beat. The program holds the line as one constant and checks it against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
